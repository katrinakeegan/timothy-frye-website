# Timothy Frye's website

Source for Timothy Frye's academic website, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and hosted on GitHub Pages.

Any change pushed to the `main` branch is published automatically after about five minutes.

To update the site (add a publication, replace the CV, add a book), see [MAINTAINING.md](MAINTAINING.md).
